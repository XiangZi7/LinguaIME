## 性能样本

原生候选视觉已通过同一 Direct2D 管线导出三种模式的实际像素检查，包含透明圆角、短阴影、默认浅青选中态、头部输入模式和选中项详情。新版本已更新系统注册，并重新通过 TSF 启用、COM 加载和进程内 profile 激活检查；已加载旧 DLL 的应用需要重开后使用新版。

完整词典 121,202 条。单次 release 样本：冷初始化约 304 ms；700 次热查询 P95 约 36 μs。命令：`cargo run -p ime-core --example benchmark --release --offline`。

该结果只测内存检索，不包含应用焦点、TSF 编辑锁、窗口绘制和磁盘写入，不作为完整端到端性能承诺。开发机、词典、优化与进程状态变化会影响结果。
